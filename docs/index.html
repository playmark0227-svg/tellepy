やること

やることは、依頼文を貼ることだけ

どこから探すかは、こちらで決めます。CSVを用意する必要も、zipを解凍する必要もありません。

01

依頼文を貼る

「工務店・不動産、従業員10-20名、一都三県で1000件」——お客様からの文面をそのまま貼れば、業種・エリア・規模・件数を読み取ります。「一都三県」「関西」もそのまま通ります。

02

名簿は要りません

CSVを探してくる必要も、zipを解凍する必要もありません。AIが公開されているホームページを見つけて、そこから社名・所在地・電話番号を拾います。手元に名簿がある場合は、そちらから無料で絞り込むこともできます。

03

出どころを示せない会社は入れない

AIは「それらしい社名」を作れてしまいます。だから telepy は、検索結果で実在を確認できて、出どころのURLを示せた会社だけを残します。新しい会社が出てこなくなったら、数合わせをせずそこで止めます。

04

分かっていないことを、隠さない

電話番号が取れなかった会社は空欄のまま出します。AIが判断した行には印が付き、規模の条件は「希望として伝えただけ」と明示します。そのまま上司とクライアントに見せられる状態で渡します。

料金

お金がかかるのは、電話番号を調べるところだけ

会社を探して名簿にするところまでは、通信も課金も発生しません。有料の工程は、押す前に金額が出て、上限に達したら自動で止まります。

無料

¥0

手元の名簿（国税庁データ等）から絞り込む場合。CSV/zipの読み込み・絞り込み・CSVの書き出し。この端末の中だけで動き、通信もしません。

従量

¥0.8 / 社〜

WebからAIに探させる場合（1,000社で概算 ¥800）。名簿の会社に電話番号だけ足す場合は 1社 ¥3〜40。あなたの Anthropic APIキーで直接課金され、telepy は一切受け取りません。

無料で自動探索する方法もあります 手元で python main.py を起動し、検索モードを「Web自動探索」にすると、無料の検索エンジンで条件に合う会社のホームページを自分で探しに行きます。データを1つも用意せず、1円もかけずに、社名・住所・電話番号まで集まります。ブラウザ版で同じことをすると有料になるのは、ブラウザから外部サイトを直接読めない仕様（CORS）のためです。
