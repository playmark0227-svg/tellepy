やること

やることは、依頼文を貼ることだけ

どこから探すかは、こちらで決めます。CSVを用意する必要も、zipを解凍する必要もありません。

01

依頼文を貼る

「工務店・不動産、従業員10-20名、一都三県で1000件」——お客様からの文面をそのまま貼れば、業種・エリア・規模・件数を読み取ります。「一都三県」「関西」もそのまま通ります。

02

効かない条件は、先に言う

走らせる前に「この名簿では資本金で絞れません」と宣告します。数分待った末に0件、が起きません。✗の隣には必ず、どうすればいいかのボタンを置いています。

03

足りなければ、AIが探しに行く

手元にデータが無くても止まりません。AIがWebを検索して会社そのものを探し、社名・所在地・電話番号まで一度に集めます。出どころのURLを示せない会社は採用しません。

04

分かっていないことを、隠さない

電話番号が0件なら「架電できる 0 / 1,000 社」と出します。取れなかった数も、AIが判断した行も、必ず表示します。そのまま上司とクライアントに見せられる状態で渡します。

料金

お金がかかるのは、電話番号を調べるところだけ

会社を探して名簿にするところまでは、通信も課金も発生しません。有料の工程は、押す前に金額が出て、上限に達したら自動で止まります。

無料

¥0

会社を探して名簿にするところまで。内蔵データ・手元のCSV/zip・絞り込み・詳細CSVの書き出し。この端末の中だけで動きます。

従量

¥3〜40 / 社

電話番号と公式サイトを1社ずつ調べる工程だけ。あなたの Anthropic APIキーで直接課金され、telepy は一切受け取りません。

無料で自動探索する方法もあります 手元で python main.py を起動し、検索モードを「Web自動探索」にすると、無料の検索エンジンで条件に合う会社のホームページを自分で探しに行きます。データを1つも用意せず、1円もかけずに、社名・住所・電話番号まで集まります。ブラウザ版で同じことをすると有料になるのは、ブラウザから外部サイトを直接読めない仕様（CORS）のためです。
